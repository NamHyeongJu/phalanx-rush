# 방진 돌격대

보병 방진(3열 × 6줄, 18명)이 오크 대군을 향해 돌격하는 모바일 세로형 방치형(키우기) 웹 게임입니다.
`C:\Git\forge-clone-2`(Conquest GO!)의 캐릭터 의상·장비·주사위·UI·효과음·폰트 리소스와 장비 규칙을 사용합니다.

## 플레이

**https://namhyeongju.github.io/phalanx-rush/** — 이 주소를 열면 누구나 바로 플레이할 수 있습니다(설치·로그인 불필요, GitHub Pages).
코드를 고친 뒤 `git push`하면 1~2분 안에 같은 주소에 반영됩니다.

## 실행

**파일 하나로 실행:** `tools\build-single.ps1`을 실행하면 `방진돌격대.html` 하나가 만들어집니다. 이미지·효과음·폰트가 모두 들어 있어 더블클릭만으로 서버나 인터넷 없이 실행됩니다.

개발용으로 원본 파일을 직접 띄우려면 `start.bat`을 더블클릭하면 로컬 웹서버가 뜨고 브라우저가 `http://localhost:8080/`으로 열립니다.
(설치 필요 없음 — PowerShell로 동작. 서버 창을 닫으면 종료됩니다.)

PC 브라우저에서는 개발자도구(F12) → 기기 툴바(Ctrl+Shift+M)로 휴대폰 화면처럼 보면 가장 좋습니다.

## 게임 방법

- 방진은 자동으로 전진하다 오크를 만나면 가속 돌격해 부딪힙니다. 앞 2열은 창방패병(긴 창으로 찌르기), 맨 뒷열은 궁수입니다.
- **장비(주사위)**: 하단 장비 화면의 주사위를 누르면 포지클론2와 같은 규칙으로 장비가 나옵니다(주사위 레벨별 시대 확률 → 8부위 중 하나 → 레벨 구간 → 중세 이후 옵션). 지금 장비와 비교해 **장착**하거나 **판매**(골드 + 경험치 20)합니다. 장착하면 이전 장비는 자동으로 판매됩니다.
- **군복**: 장착한 투구·갑옷이 병사 18명 전원의 복장이 됩니다(포지클론2 플레이어 의상 전체: 갑옷 43·투구 44종). 근접 무기는 창방패병, 원거리 무기는 궁수가 듭니다.
- **주사위 레벨**: 골드와 시간을 들여 올리면 더 높은 시대(원시→양자)의 장비가 나옵니다. 보석으로 즉시 완료할 수 있습니다.
- **자동**: 1-3부터 사용 가능. 주사위를 계속 굴려 약한 장비는 판매하고, 더 좋은 장비가 나오면 멈춥니다.
- **병력 보충**: 쓰러진 병사는 일정 시간마다 자동으로 보충됩니다. **강화** 탭에서 보충 쿨타임과 한 번에 보충하는 병력 수를 올릴 수 있습니다.
- **스킬** 탭/소환: 보석으로 스킬을 뽑아 장착하면 쿨타임마다 자동 발동합니다(AUTO 끄면 슬롯을 눌러 직접 사용).
- 주사위는 오크 처치(확률), 보스, 스테이지 첫 클리어, 퀘스트, 방치 보상으로 얻습니다.
- 부대가 전멸하면 한 스테이지 후퇴해 **반복 사냥**하며, 준비되면 상단 **보스 도전!**으로 다시 전진합니다.
- 진행 상황은 브라우저에 자동 저장되며, 다시 접속하면 방치 보상을 받습니다(최대 8시간).

## 구조

- `index.html`, `css/style.css` — 화면 구성과 스타일(포지클론2 `_tokens.uss`·장비창 레이아웃 기준)
- `js/equipment.js` — 포지클론2에서 생성한 의상 매핑·장비 목록·기본 능력치·주사위 확률·레벨 구간·옵션 범위
- `js/forge.js` — 주사위 장비 생성, 장비 능력치, 장비 → 군복 변환
- `js/engine.js` — 이미지 로딩, Unity 리그(ModularBattleRig.prefab) 좌표로 파츠를 조립하는 캐릭터 렌더러, 효과음
- `js/battle.js` — 전투 시뮬레이션(고정 편성 방진, 돌격, 자동 보충, 웨이브, 스킬 연출)과 캔버스 렌더링
- `js/data.js` — 편성·적·스킬·강화·테마·퀘스트 수치표
- `js/ui.js`, `js/main.js` — UI, 경제·저장·게임 루프
- `tools/build-assets.ps1`, `tools/build-equipment.ps1` — 원본 Unity 프로젝트에서 리소스와 데이터를 가져와 `js/manifest.js`·`js/equipment.js`를 생성
- `tools/rig-test.html`, `tools/wardrobe-test.html` — 캐릭터 세트·의상 조립 결과 확인용 페이지
