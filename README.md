# 방진 돌격대

6×8 보병 방진이 오크 대군을 향해 돌격하는 모바일 세로형 방치형(키우기) 웹 게임입니다.
`C:\Git\forge-clone-2`의 캐릭터 파츠·무기·UI·효과음·폰트 리소스를 사용합니다.

## 플레이

**https://namhyeongju.github.io/phalanx-rush/** — 이 주소를 열면 누구나 바로 플레이할 수 있습니다(설치·로그인 불필요, GitHub Pages).
코드를 고친 뒤 `git push`하면 1~2분 안에 같은 주소에 반영됩니다.

## 실행

**파일 하나로 실행:** `방진돌격대.html` 파일 하나만 더블클릭하면 됩니다. 이미지·효과음·폰트가 모두 들어 있어 서버나 인터넷 없이 실행되고, 이 파일만 다른 사람에게 보내거나 웹호스팅에 올려도(필요하면 `index.html`로 이름 변경) 그대로 동작합니다.
게임을 고친 뒤에는 `tools\build-single.ps1`을 실행해 이 파일을 다시 만드세요.

개발용으로 원본 파일을 직접 띄우려면 `start.bat`을 더블클릭하면 로컬 웹서버가 뜨고 브라우저가 `http://localhost:8080/`으로 열립니다.
(설치 필요 없음 — PowerShell로 동작. 서버 창을 닫으면 종료됩니다.)

PC 브라우저에서는 개발자도구(F12) → 기기 툴바(Ctrl+Shift+M)로 휴대폰 화면처럼 보면 가장 좋습니다.
`index.html`을 직접 열어도 실행되지만, 폰트와 효과음은 웹서버로 실행해야 정상 동작합니다.

## 게임 방법

- 방진은 자동으로 전진하다 오크를 만나면 가속 돌격해 부딪힙니다. 근접병은 전열, 창병은 2열까지, 궁수·총사·마법사는 후열에서 공격합니다.
- 병사가 쓰러지면 **병사 뽑기**로 빈자리를 보충합니다(길게 누르면 연속 뽑기). 모집할수록 모집 레벨이 올라 고급 병사 확률이 오릅니다.
- 등급(일반→고급→희귀→영웅→전설→신화)마다 원시·청동·고전·중세·증기기사·양자 시대 갑옷을 입고 무기도 바뀝니다.
- **부대** 탭의 합성: 같은 등급 3명 → 한 단계 높은 등급 1명. 남는 자리는 다시 뽑기로 채웁니다.
- **스킬** 탭/소환: 보석으로 스킬을 뽑아 장착하면 쿨타임마다 자동 발동합니다(AUTO 끄면 슬롯을 눌러 직접 사용). 중복 획득으로 레벨업.
- **강화** 탭: 골드로 공격력·체력·공속·치명타·마력·방패벽·골드 획득·행군 속도를 올립니다.
- 부대가 전멸하면 한 스테이지 후퇴해 **반복 사냥**하며, 준비되면 상단 **보스 도전!**으로 다시 전진합니다.
- 진행 상황은 브라우저에 자동 저장되며, 다시 접속하면 방치 보상을 받습니다(최대 8시간).

## 구조

- `index.html`, `css/style.css` — 화면 구성과 스타일
- `js/engine.js` — 이미지 로딩, Unity 리그(ModularBattleRig.prefab) 좌표로 파츠를 조립하는 캐릭터 렌더러, 효과음
- `js/battle.js` — 전투 시뮬레이션(레인·랭크 방진, 돌격, 웨이브, 스킬 연출)과 캔버스 렌더링
- `js/data.js` — 등급·병종·적·스킬·강화·테마·퀘스트 수치표
- `js/ui.js`, `js/main.js` — UI, 경제·저장·게임 루프
- `tools/build-assets.ps1` — 원본 Unity 프로젝트에서 리소스를 복사·리사이즈·슬라이스하고 `js/manifest.js`(파츠 크기·피벗)를 생성
- `tools/rig-test.html` — 모든 캐릭터 세트 조립 결과를 한눈에 보는 확인용 페이지
